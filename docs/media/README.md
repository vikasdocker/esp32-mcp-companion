# Media

This folder is intended for project photos and demo videos (device, UI, setup flow, hardware).

## Included

- `project-tree.svg` — animated project structure diagram generated from the repository layout.

## To add captures

Add your own files here, for example:

- `photos/` — board, wiring, screen/UI photos
- `videos/` — short demos (chat flow, boot/setup, tunnel/bridge working)

Then reference them from the root `README.md`.

> Note: physical photo/video capture requires access to the device/camera and was not performed automatically in this environment.
